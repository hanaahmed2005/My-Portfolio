HANA AHMED — DARK VINTAGE PORTFOLIO
===================================

THEME
Dark midnight navy with muted lavender accents, keeping the vintage/editorial serif style.

PROJECT SCREENSHOTS
Add images to images/projects/:
- artify.jpg
- minecraft-landing-page.jpg
- tic-tac-toe.jpg
- salma.jpg
- anas-birthday.jpg
Recommended ratio: 16:9.

PROJECT LINKS
Each project card has Live Demo and GitHub links. Artify and Minecraft have current demo URLs in the template. Replace the ADD_*_LIVE_DEMO_URL placeholders for Tic Tac Toe, Salma, and Anas Birthday with their actual deployed URLs.

CERTIFICATES FROM LINKEDIN
Add certificate images to images/certificates/:
- certificate-01.jpg
- certificate-02.jpg
- certificate-03.jpg
Then edit the matching certificate card in index.html with the real certificate name, issuing organization, year, and exact LinkedIn post/credential URL. Duplicate a certificate-card block to add more. No certificate details are invented in this template.

BEFORE PUBLISHING
1. Replace YOUR_EMAIL@example.com with your email.
2. Replace ADD-YOUR-LINKEDIN-USERNAME with your LinkedIn profile username.
3. Check repository links and descriptions; update any repository slug if needed.
4. Replace all ADD_* placeholders with real links.

PUBLISH WITH GITHUB PAGES
Upload all files and folders to your repository. Go to Settings > Pages > Deploy from a branch > main > /(root) > Save.

TECHNOLOGY
HTML5 + CSS3 only. Devicon skill logos load from CDN, so an internet connection is needed.
